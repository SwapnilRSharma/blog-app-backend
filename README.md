# blog-app-backend

To run the project locally:

1. Install dependencies: `npm install`
2. Create `config/dev.env` with the following variables:

   MONGODB_URL=mongodb://127.0.0.1:27017/blog-api
   JWT_SECRET=replace-with-a-strong-secret
   PORT=4000

3. Start in dev mode: `npm run dev`

See the full API and repository overview in `docs/repo-summary.md`.
